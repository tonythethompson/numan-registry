The repository is a data-only catalog centered on `registry/index.json` (canonical JSON) plus its detached Ed25519 signature in `registry/index.json.sig`, verified against the committed public key in `keys/official.pub`. Three sibling domains collaborate around this artifact — `registry_and_specs/` defines and stores the schema and per-package spec files that feed the index; `scripts/` provides the toolchain to scaffold entries, validate canonical form + signature, run lifecycle proofs against real Nu, build mirror archives, and provision production keys; `docs/` holds the maintainer playbooks (key provisioning, rotation, cutover, intake tracking, incident response). GitHub Actions workflows (`staging.yml`, `production.yml`, `repo-safety.yml`) wire these pieces together: staging signs with an ephemeral key, production signs only after all no-secret validation passes using the protected `NUMAN_REGISTRY_PRIVATE_KEY`, and repo-safety runs secret scans, preflight checks, schema/parser validation, and manifest↔index linting. The `tools/numan-parser-check/` directory pins Numan's production Rust parser to cross-validate the index at deploy time.
