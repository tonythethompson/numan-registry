Scripts run directly with `python3 scripts/<name>.py` and require no package manager. Optional dependencies must be installed manually: `pip install cryptography jsonschema`. `provision-production-key.sh` requires `python3 -m pip install --user cryptography` before use. `lifecycle-prove.py` requires both `numan` and `nu` executables on PATH or passed via `--numan`/`--nu`. `sync-intake-candidates.py` optionally calls the `gh` CLI for GitHub PR/issue lookups.
