Outreach issues are filed with `gh issue create --repo <owner>/<repo> --title "..." --body-file docs/outreach-issues/<file>.md`. After an upstream ships assets, update `docs/intake-state.json` then run `python scripts/sync-intake-candidates.py` to regenerate downstream artifacts. Lifecycle verification is run via `python scripts/lifecycle-prove.py --package owner/name` on a clean root.
