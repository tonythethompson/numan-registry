Pure Python 3.9+ using only stdlib (`urllib`, `hashlib`, `json`, `subprocess`, `zipfile`, `pathlib`); optional `cryptography` for Ed25519 signing/verification and `jsonschema` for schema validation, both imported lazily inside functions with explicit `pip install` hints on ImportError. Ed25519 raw 32-byte keys are used throughout; canonical JSON uses sorted keys and compact separators (`separators=(",", ":")`) to match the Rust client's `official_registry.rs` verification path.
