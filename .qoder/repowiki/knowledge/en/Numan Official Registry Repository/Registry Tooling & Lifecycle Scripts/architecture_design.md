Flat collection of independent CLI tools plus two shared Python modules (`nu_version_constraint.py`, `archive_formats.py`) imported by multiple scripts. Each script is self-contained with its own `argparse`-based CLI and an `if __name__ == "__main__": sys.exit(main())` entry point; dependency direction is one-way — utility scripts import the shared constraint/archive modules but never each other. Cross-cutting cryptographic and serialization logic lives in `validate.py` (canonical JSON, Ed25519 verification, schema validation) which is reused by `ci-sign.py`, `provision-production-key.sh`, and `preflight.py`. The workflow boundary is explicit: intake tools (`add-package.py`, `build-mirror-zip.py`, `sync-intake-candidates.py`) produce artifacts; validation tools (`validate.py`, `lint-manifest-index.py`, `lint_packages.py`) check them; signing tools (`ci-sign.py`, `provision-production-key.sh`) sign them; lifecycle proof (`lifecycle-prove.py`) exercises them against a real `numan`/`nu` installation. Test files (`test_*.py`) mirror each tool under test and live alongside it. Shell entrypoints delegate cryptographic work to embedded Python heredocs rather than external binaries.
